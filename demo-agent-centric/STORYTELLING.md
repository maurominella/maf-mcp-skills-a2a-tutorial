# Storytelling — introducing the Agent-Centric harness

Speaker notes for the workshop section that comes **after** the typical phases
(Discovery, Architecture, Security, Delivery planning, Implementation, Deployment)
have been presented, and **before** the live demo.

## 1. The problem

*"Today each of us uses Copilot in our own way: a different prompt, a different
result. It works, but it is not a method. And a company cannot deliver projects
based on the talent of whoever writes the prompt."*

## 2. The idea

*"An experienced consulting team never starts from scratch with each customer: it
has a methodology, roles, templates, standards, and artifacts. Let's do the same with AI: give
Copilot our methodology, not just a question."*

## 3. The harness, prepared once

*"Before any project, we prepare a kit. We build it with Copilot, but the decisions
are ours. It contains three things:"*

- **the process**: the 6 phases you have just seen, with the points where a human approves;
- **the skills**, that is, the roles: most are ready-made from Microsoft and the
  community; only a few are written by us, where we hold knowledge nobody else has
  (how we run discovery, our security baseline);
- **the project template**: the folder structure in which each phase stores its result.

*"This kit is a company asset: versioned, reviewed, and improved over time, like any
other internal standard."*

> Key nuance: Copilot helps build the kit, but its content — phases, approvals,
> security baseline, which external skills to adopt — is an organizational decision.
> Copilot drafts; the organization validates and owns it.

## 4. Every new project

*"From now on, starting a project takes a few minutes: one command creates the repository
with the process and the skills inside, always up to date. Then the user does only
one thing: say what they want to build."*

## 5. Transition to the demo

*"Let's see it. We invent only one thing, the topic: a solution to book meeting
rooms. The phases are our standard process, already in the harness. What I will not
give Copilot is everything else: the questions to ask, the architecture, the security
checks that matter, the backlog. Watch how the system fills each phase on its own,
starting from a single sentence."*

> Be explicit with the audience: the organization decides **which** phases every
> project goes through; the harness decides **what** happens inside each phase for
> the specific project.

## 6. Closing, after the demo

*"Tomorrow, with the same kit, we can start from a completely different topic. The
project changes; the method does not. The center is no longer the model: it is the
process."*
